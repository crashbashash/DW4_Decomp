# game.elf's module map

_Generated by `scripts/module_map.py` -- do not hand-edit._

`config/SLUS-20836/symbols.txt` carries an address for every function but only names some; the rest are `FUN_*`. The strings a function references identify it, and vendor code is loud about itself, so contiguous runs of symbols (a run is the original translation unit -- MWCC emits a unit's functions in source order) can be attributed to a library. The label table lives in `scripts/module_map.py` and is printed next to its evidence so it can be checked.

**Why it matters:** of the 2,097 raw casts applied to a function's receiver (finding [#486](../findings/findings-0251-0500.md#f486)), **1,676 (85%) are in third-party middleware**, not game code. Naming vendor internals buys nothing for either goal -- a port replaces the middleware wholesale -- so P1.3's queue is the game-code remainder.
