# The platform seam

_Generated by `scripts/gen_platform_seam.py` -- do not hand-edit._

The engine is written against **generic** platform classes and the PS2 implementations sit underneath them, so a port implements the generic side and the engine logic above it runs unchanged. The seam is recovered from the data rather than asserted: `data/class-hierarchy.tsv` gives each class's base, and `data/reflection.json` gives that base's fields with names, offsets and metafield types.

**31 `igPsx2*` classes sit under 30 generic interfaces carrying 153 fields.** The exception is `igPsx2IopRpcConnection`, which derives from `igObject` instead -- that is the RPC seam itself and it is deleted on a port.
