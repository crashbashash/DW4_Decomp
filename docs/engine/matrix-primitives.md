# Matrix copy and translation primitives

The complete five-body copy/translation run at `0x001908f0..0x00190b24`
(540 code bytes).
The construction/get/set bodies are in
[matrix-primitives.c](../../src/engine/matrix-primitives.c).
Names are semantic operations generated by
[`seed_names_matrix_primitives.py`](../../scripts/seed_names_matrix_primitives.py),
not assertions about original class or method spelling.

| Address | Operation | Contract |
| --- | --- | --- |
| `0x1908f0` | Matrix44_Copy | Copy 64 bytes; guest-pointer alignment selects snapshot versus forward word copy |
| `0x1909b0` | Matrix44_FromTranslation | Write identity's first twelve words, copy three vector words to indices 12–14, write index 15 as 1 |
| `0x190a10` | Matrix44_SetTranslation | Sequentially copy vector words to matrix indices 12–14 |
| `0x190a30` | Matrix44_GetTranslation | Sequentially copy matrix indices 12–14 to vector output |
| `0x190a50` | Matrix44_TranslateLocal | Add basis-weighted vector components to all four words at indices 12–15 |

## Alignment, aliases and float behavior

Copy tests `(destination | source) & 15`. With both addresses 16-byte aligned,
four LQ instructions load all 64 bytes before any SQ store. That path preserves
an overlapping source as a complete snapshot. Otherwise the routine copies
sixteen float words forward, interleaving each load and store. Overlap can
propagate already overwritten words; substituting memmove would change retail
behavior on that path. The test is on the addresses themselves; invalid
word-alignment exception behavior is outside this contract.

Construction writes the identity basis before reading the vector, preserving
aliases where the source vector overlaps those words. Get/set copy sequentially
as well. Local translation handles rows 0 to 3 in order, reloading the three vector
components each time: word `12 + row` becomes its old value plus
`((m[row] * x + m[4 + row] * y) + m[8 + row] * z)`. Aliases with translation storage
therefore observe earlier writes. It updates
the fourth stored translation word too, so it is not limited to affine matrices.
The arithmetic follows the [EE float rules](action2-timing.md#floating-point-is-not-host-floating-point).

## Source shapes

FromTranslation (84 bytes) is
ordinary readable float-array C; get and set are
28 bytes each. Copy needs a matching representation of its quadword
path. Local translation's natural expression gets its size and shape right but
differs in multiply operand scheduling. This five-body subgroup is not the whole matrix
library.
