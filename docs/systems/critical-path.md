# Digimon World 4 — script progression gates

These are static script predicates, not a verified speedrun route. Decoding the script numbers with a signed bias one too large
gives incorrect flag IDs and values and a spurious Lua-to-save inversion. See the
[numeric audit](../engine/lua-numeric-audit.md).

## City teleporter predicate

`lua/05-city-overworld/01-stag0403-city-quest-hub_e709/034-layer-setup-2.lua:122` reads:

```lua
if be:FLGisOn(376) ~= 1 and be:FLGisOn(377) ~= 1 and be:FLGisOn(378) ~= 1
   and be:FLGisOn(379) ~= 1 and be:FLGisOn(380) ~= 1 then
    if be:FLGisOn(381) == 1 then
        -- generate/power on g_cytelep1; disable hitpopblockz040
    end
end
```

A `375..379 !=0 AND 380 ==0` reading of this condition is the signed-bias error. This predicate
alone does not establish the whole game's critical path or an area-to-flag
mapping. In particular, do not label it the only final-boss gate without
checking the stage-transition and persistent-folder services.

## Machine Pit stages

`lua/05-city-overworld/` is misnamed: its stages are Machine Pit areas, not a city (`stag0401` Battle
Arena, `stag0403` Mechanical Core, `stag0404` Core Area). `stag0403` is the World 4 content hub, with
exits to `dng411b1`, `dng412b1`, the `dngq*` quest dungeons and `stagML11`. `stag0401` has no scripts
and no exits, and is reached from the World 4 and quest dungeons. No exit script in another stage
names `stag0403` or `stag0404`: `stag0403`'s only script reference is its own reload in
`026-flag-905.lua` after the starship cutscene.

## Persistent folders

Exactly one stage exit tests a persistent folder: `stag0102` to `stag0103` requires folder 2
(`013-exit-to-stag0103.lua`). The other folder checks are not transitions:

| Stage | Folders | Effect |
| --- | --- | --- |
| `stag0101` | 0, 1 | sets flag 900 for an in-stage switch |
| `stag0202` | 4, 5 | sets flag 901 for an in-stage switch |
| `stag0302` | 6, 7, 8 | sets flag 902 for `n_gekoa` dialogue |
| `stag0403` | 9, 10 | sets flag 905 for the arrival sequence |
| `dngq3b2e` | 11 | picks a quest reward |

The `stag0101` Goblin Fortress gate `g_gobgatez01` is opened unconditionally in
`017-layer-setup-2.lua`. A folder check in a layer or NPC script is not evidence of a gate: trace the
flag it sets to what that flag controls.

## The final chain

The final chain advances on gate objects, not flags. `e751/009-exit-to-stagbs05.lua` and
`e758/018-exit-to-stagbs06.lua` fire when `g_dbossgate` is live, and `e765/012-exit-to-stagis20.lua`
when `g_dreturngate` is live; none of the three tests a flag. Each gate is generated by that phase's
victory script (`017-boss-devl1e.lua`, `014-boss-devl21-2.lua`, `005-boss-devl31.lua`). The flag
writes in the final victory block are bookkeeping and do not gate the ending.

## Validation boundary

Generated [flag cross-references](flags/flag-xref.tsv) contain all 11,866
operations and their original entry/chunk/line evidence. Numeric source
regeneration is checked by `scripts/verify_lua_decode.py`. These readable scripts
remain analysis output with best-effort control-flow reconstruction. Progression outcomes still require
matched retail state/input comparisons.

## Open questions

- How key items gate travel is unproven. The key-item descriptions (disc offsets `0x7B38A2B` and
  `0x7E329FB`) say Mammothmon ID opens the gate to Goblin Fortress, SkullGrey ID the gate to Station
  X, Shogun ID gets through Mangrove Forest, Boat Key the boat at Numenume River, Ophanimon ID the
  Home Server protection, and Offering calms the ghost in the Forbidden Shrine. Only one stage exit
  tests a folder ([Persistent folders](#persistent-folders)), so the mechanism behind these
  descriptions still needs tracing.
